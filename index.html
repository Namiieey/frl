Recommended Firestore Security Rules

To ensure patient privacy, configure these rules in your Firebase Console → Firestore Database → Rules tab: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Only authenticated clinic staff can access patient and medical records
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
